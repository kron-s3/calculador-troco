# Sistema de Cálculo de Troco
Este programa é um projeto de minha autoria que agiliza o calculo do troco no fechamento de caixa em supermercados.

## Problemas
O cálculo manual de troco:
- É suscetível a erros
- Consome tempo no fechamento de caixa

## Objetivo
Automatizar o cálculo de troco de forma rápida, precisa e confiável.
